# 声明式轻量定时任务

主机专属任务写在 `hosts/<host>/tasks/<name>.nix` 自动注册，功能可经 `shelken.tasks.<name>` 声明；复杂生命周期服务作为独立功能实现，不走本框架。使用步骤见 [定时任务用户指南](../../../../docs/user-guide/01-tasks.md)

## 编写建议

- 任务涉及外部项目且项目已有 `mise.toml` 时，`packages` 优先只声明 `mise` 与少量宿主机基础工具（如 `git`），项目内命令先 `cd` 进仓库再通过 `mise exec --` 执行，让项目工具链由项目自身单源维护，避免升级后与本仓 `packages` 漂移

## 考虑过的替代方案

- 保留手动开关：多一层间接与样板，违背「加文件即生效」
- 自制 Cron 解析引擎：维护负担大，丢失 launchd 唤醒后补跑的语义
