# 自研 CLI 的设计取舍

适用于设计或修改任何自研命令

## 使用者视角

- 磁盘占用最低：必需前置只含轻量依赖，重依赖只出现在可选路径上
- 复用率最高：复用 nix store、mise 共用安装层和已有产物，状态已就绪就直接使用，不重复下载或构建
- 来源可信：二进制取自官方 release、nix 缓存或 mise，下载后先校验 sha256
- 配置最少：必填项只留无法探测的那一项
- 手动环节最少：必须由用户亲手做的步骤，用脚本或可直接复制的完整命令降低步骤数
- 有帮助输出(`--help`): 输出常用的命令和参数, 控制输出在50行内, 提供`更详细参数(例如-v)`支持完整输出
- 有`--debug`: 输出详细的可观测数据, 例如多阶段运行时间

## 维护者视角

- 代码至少 6 个月后仍能读懂和修改

## 依赖与下载

- CLI 自己只下载必需的产物，其余外部工具只经 nix 或 mise 引入
- 优先引入预编译二进制并复用，避免从源码构建
- 外部资源写成脚本开头的常量，固定版本并附哈希，运行时不解析版本

## 路径选择

- 按本机条件探测并自动选路，用户不选
- 首选依赖缺失时依次降级，保留兜底路径
- 尚未验证的路径，在输出和文档里标「未验证」

## 可见性

- 提供一条命令，让用户看清当前状况，如将走哪条路径、剩余额度
