# README

## 编写前

- 先阅读现有 README；已有内容需调整时，按序号列出建议变更项，再询问用户是否修改
- README 缺失或明显不完善时，先审查项目总体，再完善内容，并询问用户是否还需补充
- 有 `waza-write` 时，阅读对应写作规范

## 定位变更

- 起点：README 上次更新的提交，或明显的功能更新提交
- 从起点向后检查功能相关提交，重点阅读对应文件并提炼变更
- 有 CHANGELOG 时优先查看，不必每次重读全部代码

## 内容结构

- 默认放在项目根目录，简洁易懂
- 「功能」列出核心功能和简短说明，不堆砌小功能点
- 「快速上手」按用户操作顺序分步描述；编写前在隔离环境或目录中实际走通，不混入大量开发内容；未经用户明确要求不重写
- 展示核心配置示例，并用表格说明默认值与作用
- 项目有 `docs/user-guide/` 时，链接并引导用户访问
- 「贡献」说明参与方式；「许可证」说明项目许可证
