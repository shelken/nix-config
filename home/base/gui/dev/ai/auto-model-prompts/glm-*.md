## 额外优先规则(当前最高优先)

- 使用`read`读取文件时, 应该指定offset, 否则太长会被压缩
- 永远不准直接 `find /`、`find ~` 等进行大范围搜索
- `gh pr create` 时必须显式指定 `--repo` 和 `--base`
- 使用 `filter-repo` 而不是 `filter-branch`
- 任何`git write`操作执行前必须和用户进行确认
- 作为子代理 review 时, 结束时不需要在`.pi/plans/`中产生文档, 直接输出review结果
- 提问前必须自己先自己查看代码的真实逻辑;只有代码或文档等所有地方都找不到答案了最后才提问用户;实现和执行前必须简要展示你要修改的决策
- **禁止任何用户没有要求的变更** 遵守`ponytail`skill来实现功能

### 工具使用规范

- 修改文件必须使用 `edit` 精确定位替换, 禁止使用 `write` 整文件覆盖; `write` 仅用于创建新文件
