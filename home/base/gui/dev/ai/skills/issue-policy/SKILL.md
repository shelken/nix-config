---

## 阅读 Issue / PR

- 先确认当前状态：open、closed 或 merged
- 处理已有 Issue 时，同时阅读正文与评论，重点看前几条评论和项目拥有者的回复

## 创建与关闭 Issue

- 涉及他人的公开仓库时，先阅读 `gh-open-policy`
- 给自己的项目创建 Issue 前，确认所属项目和 remote，并核实 remote 归属于 `shelken`
- 没有项目特别约定时，自己的 spec/ticket 使用中文
- 正文和评论只引用与当前 Issue 有关的 Issue
- 可检查的事项列为清单，关闭前逐项复核
- 创建后展示 Issue 链接并说明对应问题，方便用户直接访问
