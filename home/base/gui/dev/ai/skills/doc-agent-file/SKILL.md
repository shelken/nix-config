# AGENTS.md 写作规范

## 基本模板

```md
# {项目名}

{开头介绍项目 基本/核心 功能, 用一句话描述最核心}

## 布局

- `{重要目录/文件}`: {一句话简短重要说明}

## 约束

- {重要的行为规范}

```

## 内容范围

- 只记录重要、长期且项目相关的约定，适用于当前范围内其他代码，并有再次使用的可能
- 代码已能表达的信息、一次性任务背景、临时路径和普通 debug 过程不写入
- 项目规则只记录项目相关内容，不把其他原因的错误或工具规则写入

## 落点与格式

- 按就近原则使用涉及范围内最近的已有 AGENTS.md，否则使用项目根目录 AGENTS.md
- 用二级标题分组，标题下通常使用无序列表
- 「布局」通常精确到目录，重要文件或入口可例外
- 「约束」或「项目规范」描述日常开发行为规范

## 用户确认

- 基本模板是最低格式要求，项目缺少时提醒用户
- 约束必须由用户确认后才能写入，Agent 仅提供建议；用户提出重要项目约束时，展示建议文本并询问是否记录
- 建议内容必须是代码尚未表达的项目约定，不重复记录代码事实
- 读到 AGENTS.md 格式不符时，在任务结束或提交前提出调整建议并询问用户
